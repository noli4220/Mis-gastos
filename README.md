# Mis gastos

App para anotar los gastos de cada día con un presupuesto mensual (del 7 al 6). Está organizada en cinco pestañas:

- **Hoy:** cuánto te queda este mes y esta semana, y anotar un gasto (rápido escribiendo "uber 12", o paso a paso).
- **Resumen:** tu semana, gráfica por día o por semana, categorías y todos los gastos del mes.
- **Metas:** metas de ahorro con barra de avance.
- **Viaje RD:** Tarjeta RD en pesos, plan por día para el viaje y convertidor.
- **Ajustes:** tu plan mensual, avisos y copia de seguridad.

- **Instalar en iPhone:** abre el link de GitHub Pages en Safari → Compartir → Agregar a pantalla de inicio.
- **Avisos:** abre la app desde el ícono → Ajustes → "Activar avisos" → manda el código a Claude. Los avisos (1:00 pm, 6:00 pm y 9:30 pm) los manda un repositorio privado aparte y dicen cuánto te queda esta semana.
- Los gastos se guardan solo en el teléfono. Usa "Copia de seguridad" en Ajustes antes de borrar la app.
